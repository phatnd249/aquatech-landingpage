# Thư mục Tài liệu Dự án (Project Docs) - VietFuture 2026

Thư mục này dùng để lưu trữ các tài liệu chính thức gửi hội đồng giám khảo và khách tham quan:

- `whitepaper.pdf`: Bản mô tả toàn diện về giải pháp công nghệ, thuật toán và tính sáng tạo.
- `bao-cao-du-an.pdf`: Báo cáo quá trình nghiên cứu, thử nghiệm và kết quả thực nghiệm.
- `api-documentation.pdf`: Tài liệu đặc tả kỹ thuật RESTful / GraphQL API và giao thức kết nối thiết bị.
- `huong-dan-trien-khai.pdf`: Sổ tay hướng dẫn cài đặt và vận hành hệ thống.
